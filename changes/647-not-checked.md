- **Copied reviews and the command-line tool say what the checks couldn't look at** ([#647](https://github.com/uncoverthestack/databricks-bundle-inspector/issues/647)), so "No issues" never hides code that wasn't read: a notebook in the workspace or in the job's Git repository, the code inside a wheel, JAR, `spark_submit` task or dbt project, R and Scala files (read for `dbutils` calls only), a `%run` the widget check couldn't follow, and widgets read by names set at run time. The short and full copied reviews list them under **Not checked**. The command-line tool prints them under each bundle, and `--format json` adds a `notChecked` list to each bundle (`schemaVersion` stays 1: fields are only added). Across 885 bundles from Databricks' examples and the Databricks CLI's tests, findings are unchanged.
