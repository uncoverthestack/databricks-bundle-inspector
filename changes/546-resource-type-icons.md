Changed

- **Resource types show an icon instead of a dot** ([#546](https://github.com/uncoverthestack/databricks-bundle-inspector/issues/546)). Boxes on the bundle overview, their search results, chips in a job's Uses row and a task's references now show an icon for their type, such as a warehouse for a SQL warehouse, a server for a cluster and a folder tree for a schema, so grey types are told apart by shape. Colours stay by type family and the type is still written beside it. Job graph task boxes, which print their type, **Serverless or inherited** compute, and a reference shown in a problem colour keep their dot.
