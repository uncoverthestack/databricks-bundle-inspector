Changed

- **Resource types show an icon instead of a dot** ([#546](https://github.com/uncoverthestack/databricks-bundle-inspector/issues/546)). Boxes on the bundle overview and chips in a job's Uses row now show an icon for their type, such as a warehouse for a SQL warehouse, a server for a cluster and a folder tree for a schema, so grey types are told apart by shape. Colours stay by type family and the type is still written beside it. Job graph task boxes, which print their type, and **Serverless or inherited** compute keep their dot.
