- **Job graph lines are grey, and a selected task's lines turn blue** ([#554](https://github.com/uncoverthestack/databricks-bundle-inspector/issues/554)). Lines used to be blue, which looked clickable, and an if/else task's True line was green, which read as "good". Now every line is grey and the False line is dashed, so red and amber on task boxes are the only colour at rest. Selecting a task turns its own lines, in and out, blue.
