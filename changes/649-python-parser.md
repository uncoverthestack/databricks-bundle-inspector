Changed

- **Python code is read with a full Python parser** ([#649](https://github.com/uncoverthestack/databricks-bundle-inspector/issues/649)). Widget, secret, task value and notebook run checks now read Python with [tree-sitter](https://tree-sitter.github.io/) instead of the inspector's own tokenizer, and each file is read once for all of them. Nothing in your code is run. Checked against 2,176 Python, notebook and SQL files from Databricks' example repositories, the Databricks CLI's tests, dqx, SQLMesh and this repository: the same results as before on every file, also with Windows line ends and non-English text, and the same findings on 885 bundles checked through Databricks CLI v1.28.0. Scala keeps the old reader. The extension and the command-line tool each ship three more files (about 0.8 MB) in a `tree-sitter` folder.
