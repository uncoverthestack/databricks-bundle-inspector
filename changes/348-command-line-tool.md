Added

- **A command-line tool runs the inspector's checks in a terminal or CI** ([#348](https://github.com/uncoverthestack/databricks-bundle-inspector/issues/348)). `npx @uncoverthestack/databricks-bundle-inspector check` checks every bundle under a folder with the same checks as the extension, and exits with `1` when it finds errors, so a pull request can fail before anything is deployed. Output as text, JSON, Markdown, or GitHub annotations with a summary on the run's page. `--target` checks a real target as the Databricks CLI resolves it, and never falls back to the structural preview. `--fail-on` sets which findings fail the run. Each finding shows how to fix it, a job written only under a target gets a note saying to check it with `--target`, and jobs defined in Python are listed as not checked. It needs the Databricks CLI `v0.299.0` or newer and Node.js 22 or newer, has no dependencies, is also published as `databricks-bundle-inspector`, and once installed runs as `dabi` for short.
